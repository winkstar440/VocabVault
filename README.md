# 多層級單字表 (Local Storage 版)

純前端、使用 **瀏覽器 Local Storage** 儲存資料的多層級單字學習 App。

## 功能

- **兩層結構**：語言大分類 → 子資料夾
- 可自由新增語言與子資料夾
- 新增 / 刪除單字
- 搜尋單字
- 文字轉語音（TTS）
- 資料儲存在本機瀏覽器，無需登入、無需雲端

## 特點

- 完全離線可用
- 不依賴 Firebase 或其他後端
- 資料只存在你自己的瀏覽器中
- 適合個人使用，隱私安全

## 技術

- 純 HTML + Tailwind CSS + Vanilla JS
- Web Speech API（發音）
- LocalStorage（資料持久化）

## 使用方式

直接打開 `index.html`，或部署到任何靜態網站託管服務（GitHub Pages / Firebase Hosting / Netlify 等）。
