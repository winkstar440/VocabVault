# 極簡雲端單字表 (VocabVault)

一個使用 Firebase 的極簡中文單字學習 App。

## 功能

- 新增 / 刪除單字
- 資料夾分類管理
- 搜尋單字與翻譯
- 文字轉語音（TTS）發音
- **雲端同步**（Firebase Anonymous Auth + Firestore）
- 手機友善介面

## 技術

- 純 HTML + Tailwind CSS + Vanilla JS
- Firebase Authentication（匿名登入）
- Cloud Firestore 儲存資料

## 注意

此專案目前設為 **Private**，僅供個人使用。
資料會根據匿名使用者 ID 分開儲存，不同裝置/瀏覽器會是不同帳號。
