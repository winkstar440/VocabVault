# 多層級單字表 (VocabVault)

純前端、使用瀏覽器 Local Storage 的多層級單字學習 App。

## 目前有兩個版本

| 檔案 | 說明 | 建議使用 |
|------|------|----------|
| `index.html` | 基礎版（新增、刪除、搜尋、發音） | 舊版 |
| **`index-edit.html`** | **最新版**：支援編輯單字、記住上次位置、匯出備份 | **推薦使用** |

## 最新版功能（index-edit.html）

- 兩層結構：語言大分類 → 子資料夾
- 新增 / **編輯** / 刪除單字
- 搜尋單字
- 文字轉語音（TTS）
- **記住上次開啟的語言與子資料夾**
- **匯出所有資料為 JSON 備份檔**
- 資料儲存在本機瀏覽器，無需登入

## 使用方式

直接打開 `index-edit.html` 即可使用最新版。

資料存在瀏覽器的 Local Storage 中，清除瀏覽器資料會遺失，建議定期點「匯出」備份。
